# Alex Store

Tienda personal de aplicaciones para SideStore.

## Fuente de SideStore

Añade esta dirección como fuente en SideStore:

`https://raw.githubusercontent.com/alexuvebe/Alex-Store/main/apps.json`

El catálogo está creado y alojado en este repositorio público. De momento no incluye aplicaciones: añadiremos Alex_UveBe cuando exista una versión IPA de distribución comprobada, con su versión, tamaño y enlace real de descarga.

## Distribución

- El código fuente de Alex_UveBe permanece en su repositorio privado.
- Las versiones publicadas se alojarán en GitHub Releases.
- El catálogo `apps.json` se actualizará con cada lanzamiento para que SideStore pueda detectar las actualizaciones.

No se publican aquí claves API, secretos ni código privado.
